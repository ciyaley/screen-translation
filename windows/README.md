# ScreenTranslate for Windows

コマンド操作や `.NET` の事前インストール不要で、通常のデスクトップアプリとしてダブルクリックでそのまま起動・利用できるリアルタイム画面翻訳アプリです。macOS 版と共通のダークすりガラス・モノクロUIを採用しています。

## 使い方（Windows 10 / 11）

1. **`ScreenTranslate.exe` をダブルクリックして起動**
   * 単一実行ファイル（ランタイム内蔵）のため、追加ランタイムの導入やコマンド実行は不要です。
2. **初回のみアプリ内のボタンで翻訳モデルを取得**
   * 初回起動時にウィンドウ内に表示される **`PLaMo 2B を取得 (1.8 GB)`** または **`0.8B 軽量版 (570 MB)`** をクリックすると、推論エンジンとモデルがアプリ内のプログレス表示つきで自動ダウンロードされ、完了と同時にそのまま使えるようになります（途中一時停止・レジューム再開対応、Vulkan非対応環境でのCPU互換自動フォールバック搭載）。
   * 2回目以降の起動ではダウンロードなしで即座に待機状態になります。
3. **デスクトップ／スタートメニューへの登録・GPUランタイム切替（任意）**
   * 右上の設定ボタンから **`デスクトップ＆スタートメニューに登録`** を選ぶと、`%LOCALAPPDATA%\Programs\ScreenTranslate` へ配置され、デスクトップとスタートメニューにアイコン付きショートカットが作成されます（管理者権限不要）。
   * 同じメニューから推論ランタイム（`Vulkan GPU` / `NVIDIA CUDA` / `CPU 互換モード`）の切り替えも可能です。
4. **終了方法**
   * 左上の **`✕` ボタン**（または `Alt+F4` / `Ctrl+Q` / `Alt+Shift+Q`）で閉じると、バックグラウンドの推論エンジンも OS の JobObject 連動により自動で完全終了し、VRAM・メモリが即座に解放されます。

## 主な機能・ショートカット

* **3つの表示モード（ヘッダーピルまたは `Alt+Shift+M`）**:
  * `カード`: まとまりごとに番号付きカード表示（ホバーで画面側の該当箇所をエメラルド枠ハイライト・スクロール時は既訳を **0ms キャッシュ** 維持）
  * `直接重畳`: ゲーム画面の原文座標の上にクリックスルー翻訳チップを直接表示（マウス接近時は自動で `Opacity = 0.12` に透過）
  * `近傍のみ`: マウスカーソル直下・近傍の1まとまりだけを翻訳
* **ショートカット**:
  * `Alt+Shift+R`: 監視範囲をドラッグ選択
  * `Alt+Shift+T`: 監視の開始 / 一時停止
  * `Alt+Shift+M`: 表示モード切替
  * `Alt+Shift+L` / `Ctrl+K`: 38px バーへの折りたたみ / 展開（最小幅 `360px`・自動2段ヘッダー対応）
  * `Alt+Shift+W`: ウィンドウの一時非表示 / 再表示
  * `Ctrl+C`（ウィンドウアクティブ時またはカード右クリック）: 表示中の訳文をコピー
  * `Alt+Shift+Q` / `Ctrl+Q`: 終了

※ 翻訳元言語の文字認識には Windows 標準の OCR 機能を使用します（未追加の言語がある場合は Windows「設定 → 時刻と言語 → 言語と地域」から追加できます）。
